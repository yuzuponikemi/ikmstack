# プロファイル: 資格試験・一般知識体系(exam-cert)
<!-- slots: ANCHOR=典型設定 | ANCHOR_HEADING=試験での問われ方 | WHY_LABEL=なぜこの方法なのか | CASES_HEADING=よくある誤答・誤用 -->

実例: 統計検定準 1 級。社外の公開知識(教科書・試験範囲)を題材にするとき。

| 枠 | 値 |
|---|---|
| 置き場所 | 任意のフォルダ(例: `courses/<slug>/`)|
| `{ANCHOR}` | 出題範囲内の典型設定と、公開データ・自作の数値例(例: n=25、α=0.05、指数分布 λ=2) |
| `{ANCHOR_HEADING}` | 試験での問われ方 |
| `{WHY_LABEL}` | なぜこの方法なのか |
| `{CASES_HEADING}` | よくある誤答・誤用 |
| 一次資料 | 公式の出題範囲表(章の範囲を決める関門)、標準教科書・公式テキスト(**節番号・定理番号で参照するだけ。本文・問題・図を転載しない**)、原論文・公開講義ノート |
| ダイジェスト分割の目安 | S1 出題範囲表と章対応 / S2 定義・記法の対照(教科書ごとの流儀差) / S3 頻出の問われ方(自作の言い換えで要約。過去問の本文は写さない) |
| 食い違い台帳 | 定義・記法・パラメータ化の流儀差(例: 標本分散の分母 n / n−1、指数分布のレート/平均パラメータ、尤度比統計量の符号)。「どちらでも正しいが、問題文の定義に合わせる」型の注意点 |
| 再計算の方法 | **すべての計算例・確認問題・操作図の初期読み値を Python(numpy/scipy)で再計算**し、解析解が無いものはモンテカルロ(seed 固定)で確かめる。スクリプトは `authoring/verify/Cxx_verify.py` に残す |
| `math` | katex(雛形の 3 行を残す) |
| 事例 `.case` の出典 | 教科書の節番号、公開されている誤用の解説記事・論文(例: ASA の p 値声明 2016) |
| 完了後 | `learn` スキルでの対話演習(確認問題を起点に)。つまずきを章へ反映 |

注意:
- 確認問題はすべてオリジナル。過去問の数値や文面を流用しない(形式・難度だけ寄せる)。
- 「試験での問われ方」には出題の型(記述・選択・数値計算)と頻出の落とし穴を書く。合格基準や配点は公式に公開されている範囲だけを出典付きで書く。
- 外部の数値(分位点・公式の値)は scipy で再計算した値を正とし、教科書の付表との差は丸めの差として扱う。
