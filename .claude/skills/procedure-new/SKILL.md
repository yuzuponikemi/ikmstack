# procedure-new — 手順書3層セットを起こす(authoring)

手順書の「作る」側。reviewer（runbook-review / readability-review）が検査役なのに対し、これは
**生成役**。散らかった素材（既存の1枚もの手順書・熟練者の生ログ・チャット・口頭）を、
3層トリロジーへ**振り分けて**、ひな型から3枚を生成する。ソフトでいう「ビルド手順」にあたり、
これがあって初めて「あの3層セットをまた作る」が再現可能になる。

- **3層の定義と振り分けルール**: 本 SKILL.md の下記「3層の振り分け」。
- **骨格**: `templates/{e2e-runbook,principles-triage,operation-notes}.template.html`

## 入力(ユーザーに確認。引数で与えられていれば省略)

1. **素材(source)**: 既存手順書のパス/URL、熟練者の生ログ、チャット、口頭ダンプ、または「トピック名だけ」。
2. **対象手順名**と**出力先フォルダ**（例: `.../<procedure-slug>/`。実験の検証なら experiment 配下でよい）。
3. **3層すべて要るか**: 単純作業なら①だけ、判断が要るなら①②、暗黙知が厚いなら①②③。既定は3層。

## 核となる原則(この順で効く)

- **振り分けはするが、無い情報は作らない**。素材に無い手順・根拠・数値は**推測で埋めない**
  （distrust-by-construction）。①は ⟦FILL⟧、②は OPEN として穴を可視化する。
- **層を混ぜない**。①に Why/手触りを書かない。混ぜると①が読めなくなり罠が再発する。
- **一言テストで層を決める**: なぞれば足りる→① / なぜ・異常時・誰を呼ぶ→② / コツ・勘所・過去の失敗→③。

## 手順

1. **素材を読み、断片を層にタグ付け**する（一言テスト）。
   - 実行アクション→①、根拠/判断/優先順位/エスカレーション→②、背景/五感/罠/応用→③。
   - 素材のレビューコメント・未解決質問は捨てない：②の **OPEN**（答えを創作しない）へ回す。
2. **ひな型を複製して埋める**。`templates/*.html` を出力先へコピーし、対象手順名に合わせてリネーム
   （例 `e2e-runbook.html` / `principles-triage.html` / `operation-notes.html`）。
   各ファイルの `nav` と `xlinks` の `[[...html]]` を実ファイル名に置換し、3層を相互リンクで繋ぐ。
   `authoring-guide` の枠と未使用サンプルは削除する。
3. **① を runbook-review に掛ける**（原子性ゲート）。
   - 「装置を全く知らない実行者」の隔離サブエージェントで実行不能ステップを炙り出す。
   - 実行可能な粒度に**割る**。素材に割る情報が無ければ **`⟦FILL: 何が足りない — 記入者: 役割⟧`** を置く。
   - **⟦FILL⟧ が1つでも残る①は未完成＝リリース不可**。冒頭にゲート状態バナーを出す。
     (正本: `.claude/skills/runbook-review/SKILL.md`)
4. **②③ を readability-review に掛ける**（意味の自走性）。
   - 未定義の固有名詞・略語を初出定義で補う。②の未解決事項は OPEN のまま明示（創作しない）。
     (正本: `.claude/skills/readability-review/SKILL.md`)
5. **成果物を出す**: 相互リンク済み3枚(HTML) + 1行のゲート状態（①の⟦FILL⟧残件数・②のOPEN件数）。
   `SendUserFile`(display:render)で3枚を見せる（リンクでなく直接レンダリング）。
6. **報告**: 各層に何を振り分けたか、①のゲート結果（N/M 実行可能・⟦FILL⟧残数）、②のOPEN、を表で。
   ⟦FILL⟧/OPEN が残る限り「未完成（誰が何を埋めるべきか）」と明言する。

## 単純な手順のとき(全3層は要らない)

- 一本道で判断も暗黙知も薄いなら **①だけ**でよい（②③を無理に作らない＝エントロピー最小）。
- ①だけでも **runbook-review は必ず掛ける**（原子性はスキップしない）。

## アンチパターン

- **素材に無い手順・根拠をそれらしく埋めて"完成"させる** → 元凶。①は⟦FILL⟧、②はOPEN。
- **①②③を1枚に混ぜる** → 罠の再発。薄く分けて相互リンク。
- **runbook-review を省く** → ①が「①のフリをした②(チェックリスト)」のまま出る。
- **素材のレビューコメント/未解決質問を握りつぶす** → ②のOPENに残し、原本へフィードバックできる形にする。

## 関連

- **検査役(このスキルが内部で呼ぶ)**: runbook-review(①の原子性)、readability-review(②③の意味)。
- **ひな型**: 本スキルの `templates/`（配色は exp-deck のブランドトークンに準拠）。
- **思想**: distrust-by-construction / エントロピー最小（harness-as-agent-OS）。
