# レポート索引(INDEX)

<topic> 検証の個別レポート一覧。新しいレポートを足したらここも更新する。

## ステータス凡例

| バッジ | 意味 |
|---|---|
| 🟢 Active | 現行・有効。結論の根拠 |
| 🟡 部分置換 | 一部が後続レポートに置換。注記参照 |
| ⚪ Historical | 旧版・参考記録。一次参照でない |

## レポート一覧

ファイル名 = `E###-R###_<YYYYMMDD>_<topic>.md`。`R###` は**この実験内で 1 から振る通し連番**で、
**日付つき一次記録だけに振る**(リビング文書 `REPORT.md` / `PLAN.md` / `DECISIONS.md` には振らない)。
次番号 = この表の最大 R + 1。改訂版は新 R にせず `<元名>_rev.md`(原本を残し旧行を 🟡 に)。

> この表は `python3 tools/report_meta.py` が各レポートのフロントマター(`status` / `summary`)から
> 生成する。**マーカ間は手で編集しない** — レポート側のフロントマターを直してスクリプトを回す。
> 配下の全レポートにフロントマターが揃って初めて自動生成される(未付与が残る間はスキップ・通知)。

## リビング文書(実験直下。1機能=1権威)

一次記録(この INDEX)とは別に、現在の正を映すリビング文書が実験直下にある:

| ファイル | 役割 |
|---|---|
| `../REPORT.md` | **最初に読む唯一の権威**。確定事実・現在の結論・未解決(現状サマリ) |
| `../PLAN.md` | 枠組み・仮説・成功基準 + 次の計画 |
| `../DECISIONS.md` | (長期campaignのみ)なぜ方針転換したかの履歴。追記型 |
